# Dashboard Reface Implementation Plan — "Terminal" Hybrid

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dark, dense "terminal" theme plus shared big-number/accent-card component CSS, and rework the dashboard markup to use them — keeping the app's sharp-corner Swiss design language and all existing themes.

**Architecture:** Part A extends `ui/themes.py` (a new token set + additive component CSS in the pure `css()` builder) — unit-tested. Part B updates `app.py`'s dashboard regions to use the new classes — manual-verified, no logic change.

**Tech Stack:** Streamlit, HTML/CSS strings, pytest.

**Reference spec:** [`docs/superpowers/specs/2026-07-14-ui-reface-design.md`](../specs/2026-07-14-ui-reface-design.md)

**Design-rule correction (important):** the mockup showed rounded tiles, but the repo's design system is strictly sharp-corner (`test_ui_themes` asserts `border-radius:0`). This reface KEEPS sharp corners app-wide — the hybrid feel comes from the dark palette, density, big numbers, and 3px accent left-borders, not from rounding. Do not introduce rounded corners.
